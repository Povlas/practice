# Investing.com ISIN bookmarklet

1. Make a new bookmark (Chrome: `Ctrl+D` → Edit, Firefox: right-click the bookmarks bar → Add Bookmark).
2. Paste the full contents of `bookmarklet.txt` as the URL.
3. Open a stock page on investing.com and click the bookmark: the ISIN is shown and copied to the clipboard.

The source is `isin-bookmarklet.js`; run `./build.sh` to regenerate `bookmarklet.txt` after editing it.
